## Accessibility

- Weapon recoil that pushes your camera backward is now affected by the screenshake slider in gameplay options

## Upgrades

- Gunship cannon Prism upgrade stats are increased more from a larger pattern size (previously the increase was basically unnoticeable)
- Fixed an issue from yesterday’s patch where some upgrade stats that were supposed to increase (or stay the same) from a larger pattern did the opposite -_-
- (Snowball Grenade) Fixed a typo in Hard Freeze’s description
- Fixed a typo where the description for Mycologist’s infection passive said that infection is cleansed by using Fungal Skewer instead of Sporelift

## Missions

- Fixed an issue where the Planetary Defense railgun targeting window sometimes wouldn’t read move inputs correctly (especially when using WASD while a controller with noisy sticks was plugged in). This should also improve move inputs when placing upgrades with a mouse while a controller is plugged in.
- Fixed an issue that could make your guns inaudible when joining an in-progress game
- Fixed an issue that could cause Hunk garages in Paid Time Off to spawn partially underground
- Fixed an issue where facility doors wouldn’t always be open if you joined an in-progress Paid Time Off mission where other players had already completed a facility objective

## Misc

- Fixed an issue where the DMLR’s battery didn’t light back up during the Supporter Pack’s reload variant
- Fixed an issue where you could inspect locked weapons or employees from the new upgrades screen
- Larry will stop talking to you if you’re playing Starrunner or in your inventory
- Fixed an issue where Plate Launcher plates sometimes wouldn’t recall correctly in multiplayer
- Standard employee upgrades now correctly show that they drop randomly from any source in the Codex
- Fixed Mycologist skin preview looking wrong in the employee select screen
- Fixed an issue where the Drop Pod would kill you if you jumped inside right as it landed
- Reduced the volume of the sound for spinning the Diffraction Driver halo
- Fire sounds for different elements on the Cycler sync to other players
- Fixed an issue where the warning popup when attempting to join certain lobbies wouldn’t focus the selected button when using a controller
- [PS5] Fixed a freeze when killing a large gunk in Cleanup Detail
