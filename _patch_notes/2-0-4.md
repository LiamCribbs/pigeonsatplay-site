## Known Issues

- [PS5] Clicking a lobby button multiple times in quick succession will permanently freeze the game

## Crashing

- Fixed a crash that occurred when navigating from certain UI elements with a controller
- [PS5] Fixed an issue where a backup save wouldn’t be loaded correctly if a main save somehow got corrupted
- [PS5] Fixed a crash that occurred when the audio engine overloaded
- Fixed a rare crash that could occur if two Plate Launcher plates managed to get stuck to each other while you were standing on one of them
- Fixed a nav mesh bug that might have caused a rare crash but idk

## Upgrades

- Fixed cleansed upgrades not counting toward fulfillments/trophies to collect x upgrades
- Fixed an issue where temporary upgrade storage above the upgrade grid would become unusable after filling it with 12 upgrades
- (Mycologist) Fixed an issue where Catapult was replacing the Fungal Skewer icon instead of Sporelift’s icon
- (Plate Launcher) Added a small range to Charging Port’s healing stat
- (Glider) Kernel Rerouting: Recharge speed is not affected by pattern size
- (Streetsweeper) Reversed speed stat on Kinetic Absorbers so the max stat is better
- (Voltaic Grenade) Fixed an issue where finishing Livewire when auto-sprint is enabled would cancel Mycologist’s Hypersprint
- (Lead Flinger) Chemical Symbiosis can also trigger on Decay, Rot, Bees, Cryo, and Water

## Ouroboros

- Fixed an issue where leaving and rejoining an ongoing Ouroboros lobby would unequip all of your Ouroboros upgrades
- Capped the max number of upgrades shown when hovering over a new weapon in Ouroboros so that it doesn’t clip off the top of the screen. These upgrade previews are now also sorted by rarity.
- Fixed an incorrect translation on the button to close the ‘cleanse upgrades’ screen

## Misc

- The Locked Bunker POI is a different color when it spawns with the elemental button variant vs the lost key variant
- Fixed an issue where opening the Locked Bunker by slotting in its battery didn’t unlock the achievement
- Fixed an issue a Relay Tower would be marked on your map if you joined a mission after it was completed
- Improve Transport Puck (upgrade drone) obstacle avoidance
- Fixed some issues when using toggle-sprint and auto-sprint together
- HUB Cannons are quieter for other players
- Fixed an issue where looping sounds of dropped upgrades would never stop playing under certain circumstances
- [Modding] Mission modifiers are indexed correctly
